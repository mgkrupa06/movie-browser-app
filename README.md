# Movie Browser App

A React Native movie browsing application using TMDB API.

## Features

- Trending Movies
- Top Rated Movies
- Upcoming Movies
- Search Movies
- Movie Details
- Trailer Playback

## Technology

- React Native
- Expo
- TMDB API
- React Navigation

## Setup

1. Install dependencies
2. Configure TMDB API key
3. Run using Expo
